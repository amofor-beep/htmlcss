Lorenz Attractor - Chaos Theory

A set of chaotic solutions to the Lorenz system - deterministic but unpredictable

dx/dt = σ(y - x)
dy/dt = x(ρ - z) - y
dz/dt = xy - βz
σ = 10 (Prandtl number), ρ = 28 (Rayleigh number), β = 8/3

The butterfly effect: tiny changes in initial conditions lead to vastly different outcomes
